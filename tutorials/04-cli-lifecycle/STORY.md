# 故事版：圖書館的借書機器人 🤖

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「學校圖書館租用機器人小幫手」的故事，幫你「感覺」出 container 的生命週期：`create`、`start`、`stop`、`kill`、`rm`，還有 `--rm`、`-it`、`-e`、`--name`、`ps -a` 和 `system prune`。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 從倉庫領出一台機器人

學校圖書館要辦「說故事週」，林老師向機器人公司租了幾台**小幫手機器人**。

機器人公司有一張「機器人設計圖」，照著設計圖就能組出一模一樣的機器人。

林老師說：「先幫我組好一台，放在圖書館門口，**但先不要開機**。」

工人把機器人組好、放在門口。機器人站得直直的，眼睛還沒亮——它已經存在了，只是還沒醒來。

隔天早上，林老師按下背後的按鈕，機器人的眼睛亮了：「早安！今天要幫忙借書嗎？」

> 這就是 **`docker create` 和 `docker start`**：create 照著 image（設計圖）建好 container，狀態是 **`Created`**，還沒開始跑；start 才讓裡面的 process 開始執行，狀態變成 **`Running`**。平常打的 `docker run` 就是一口氣做完這兩步。

---

## 每台都要有名字

機器人越來越多，大家只會說「那台」「這台」，常常搞混。

林老師在每台機器人胸前貼上名牌：「**小書**」、「**小讀**」、「**小館**」。

有個同學也想把新機器人取名叫「小書」，林老師說：「不行喔，**已經有一台叫小書了**。就算它現在在休息、沒開機，名字還是它的。」

> 這就是 **`--name`**：幫 container 取名，之後用名字操作就不用記一長串 ID。名字**不能重複**，就算舊的 container 已經停了也一樣，會出現 `Conflict. The container name "/web" is already in use`。要先 `docker rm` 舊的才能重用名字。

---

## 誰在工作、誰在休息？

林老師拿出一本**值班表**。

平常翻開只看到「**現在正在工作的**」機器人。可是她想知道全部的機器人，包括休息中的、還沒開機的，就要翻到後面的「**全部名單**」。

全部名單上寫得很清楚：「小書：工作中，已經 2 小時」、「小讀：休息中，最後說的話是『沒事，下班了』（代號 0）」、「小館：剛組好，還沒開機」。

> 這就是 **`docker ps` 和 `docker ps -a`**：`ps` 只列執行中的 container；`-a` 連停止、剛建立的都列出來。STATUS 欄會寫 `Up 2 hours`、`Exited (0)`、`Created`。括號裡的數字是 **exit code**，0 代表正常結束。

---

## 「請收拾好再下班」和「直接拔插頭」

下午五點，林老師對小書說：「**該下班囉，把手上的書放回書架再關機。**」

小書說：「好的！」它把正在借的那本書登記完、放回架上、跟最後一位同學說再見，然後才關機。

可是有一天，小讀當機了，一直在原地轉圈圈，叫它也不理。林老師等了**十秒**，它還是在轉，只好走過去**直接拔掉插頭**。

小讀瞬間停住，手上那本書「啪」一聲掉在地上，借書紀錄也只寫了一半。

> 這就是 **`docker stop` 和 `docker kill`**：stop 先送 SIGTERM（請收拾好再下班），等 **10 秒**還不結束才補一發 SIGKILL；kill 直接送 SIGKILL（拔插頭），exit code 是 **137**。所以程式一定要會處理 SIGTERM，好好收尾。shorty 會在 8 秒內收完，第 16 章會細講。

---

## 休息完還是同一台

隔天早上，林老師再按一次小書背後的按鈕。

小書醒來說：「早安！昨天下午三點，三年二班的小美借了《恐龍百科》喔。」

它還記得昨天的事，因為它是**同一台**機器人，只是休息了一晚。

可是如果林老師請公司**再組一台新的**小幫手，新的那台什麼都不記得——它是全新的。

> 這就是 **`docker start` vs `docker run`**：對 `Exited` 的 container 再 `start`，是**同一個** container，可寫層裡的東西都還在；`docker run` 永遠建立一個**新的** container。

---

## 退租：把機器人還回去

說故事週結束了，林老師要把小讀**退還給公司**。

公司說：「它還開著喔，請先讓它關機再退。如果你很趕，我們可以**直接拔插頭、馬上載走**。」

退掉之後，小讀就從值班表的全部名單上消失了，它記得的東西也全部不見。

> 這就是 **`docker rm`**：刪除 container，可寫層裡的資料跟著消失。執行中的 container 不能直接 rm，要先 stop；`docker rm -f` 是「拔插頭 + 載走」一次做完。

---

## 只租一下下的拋棄式機器人

有時候林老師只是要機器人做一件小事，例如「**幫我唸出今天的日期**」。

唸完就沒事了，但它會一直站在門口、佔一個位置、還要寫進值班表。

機器人公司推出了「**拋棄式租用**」：機器人做完那件事，就**自己走回公司**，連名單都不用寫。

> 這就是 **`--rm`**：container 結束後自動刪除。`docker run --rm alpine date` 跑完就消失，不會在 `ps -a` 留下一堆 `Exited` 的 container。

---

## 面對面聊天

有個同學想跟機器人**聊天**：問它問題、它回答，再問、再回答。

一開始，機器人的耳朵是關著的，同學說什麼它都聽不到，馬上就說「沒人跟我講話，我下班了」。

打開耳朵之後，它聽得到了，也會回答，可是它的臉上**沒有螢幕**，同學不知道它是不是在等自己說話。

最後林老師把**耳朵打開、再接上一個臉部螢幕**，機器人臉上出現一個閃爍的小游標：「請說——」聊天終於順利了。同學說「掰掰」，機器人就下班了。

> 這就是 **`-it`**：`-i` 打開 stdin（耳朵），`-t` 配一個終端機（臉部螢幕，有提示字元）。`docker run -it --rm alpine sh` 就能進入互動 shell，`exit` 結束主 process，container 也就結束。想離開但不讓它下班，按 `Ctrl+P` `Ctrl+Q`。

---

## 出門前塞一張小紙條

林老師想讓每台機器人用不同的方式打招呼。她在開機前，在機器人口袋裡**塞一張小紙條**：「打招呼的時候說：哈囉」。

機器人醒來一摸口袋，就知道要怎麼說了。

但有一次，林老師把紙條寫在**自己的筆記本上**，以為機器人看得到。結果機器人口袋裡是空的，只好說出一句空白的招呼。

> 這就是 **`-e`** 環境變數：`-e GREETING=hello` 把設定塞進 container。小心引號：`sh -c 'echo $GREETING'` 用**單引號**，`$GREETING` 才會在 container 裡展開；用雙引號的話，Git Bash 和 PowerShell 都會先用**主機上**的值（筆記本），傳進去的是空的。postgres 沒給 `-e POSTGRES_PASSWORD` 就會直接 `Exited (1)`。

---

## 期末大掃除

學期結束，圖書館的角落堆了好多已經關機、沒人要的機器人，還有一些沒貼名牌、不知道是誰的設計圖。

林老師拿出大掃除清單：「**關機的機器人全部退掉、沒人在用的通道拆掉、沒名字的設計圖丟掉。**」

但她特別交代：「**存放借書紀錄的櫃子**不要動，除非我特別說。」

> 這就是 **`docker system prune`**：刪掉停止的 container、沒用到的 network、dangling image、build cache。加 `-a` 連沒在用的 image 都刪；加 `--volumes` 才會刪 volume（借書紀錄櫃子），裡面可能有資料庫資料，要特別小心。

---

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 機器人設計圖 | **image** |
| 組好但還沒開機 | **`docker create`** → `Created` |
| 按下按鈕開機 | **`docker start`** → `Running` |
| 一口氣組好又開機 | **`docker run`** |
| 胸前的名牌 | **`--name`**（不能重複） |
| 值班表 / 全部名單 | **`docker ps`** / **`docker ps -a`** |
| 「沒事，下班了（代號 0）」 | **exit code**：`Exited (0)` |
| 請收拾好再下班，等 10 秒 | **`docker stop`**（SIGTERM → 10 秒 → SIGKILL） |
| 直接拔插頭 | **`docker kill`**（SIGKILL，exit 137） |
| 休息完還記得昨天的事 | 對同一個 container 再 **`start`** |
| 退還給公司 | **`docker rm`**（`-f` 強制） |
| 拋棄式租用 | **`--rm`** |
| 打開耳朵 + 接上臉部螢幕 | **`-i`** + **`-t`** = **`-it`** |
| 口袋裡的小紙條 | **`-e KEY=value`** |
| 紙條寫在自己的筆記本上 | 雙引號讓**主機 shell** 先展開 `$` |
| 期末大掃除 | **`docker system prune`** |
| 存放借書紀錄的櫃子 | **volume**（要 `--volumes` 才會刪） |

---

## 一句話記住

> **照設計圖組好（create）、按下開機（start），下班請它收拾好（stop）、當機才拔插頭（kill），退租才真的消失（rm）；只做一件事就用拋棄式（--rm），要聊天就打開耳朵接上螢幕（-it）。**
