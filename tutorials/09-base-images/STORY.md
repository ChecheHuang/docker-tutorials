# 故事版：植物要搬家，選哪一種盆子？ 🪴

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「幫植物選搬家盆子」的故事，幫你「感覺」出 base image、debian-slim、alpine、distroless、scratch、glibc 與 musl、`CGO_ENABLED=0`、CA 憑證、時區資料是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 植物要送去新教室

自然課的小安種了一盆小樹苗，老師說要把它送到另一棟樓的新教室，讓大家都看得到。

上次學過了：工具和肥料袋留在溫室，只把植物送過去。可是植物總要種在**某個東西**裡吧？

溫室的阿伯搬出四個盆子，放在桌上：

1. **大陶盆**：裝滿了土，還附一把小鏟子、一包肥料、一個澆水壺。
2. **小塑膠盆**：土比較少，附一支迷你鏟子。
3. **透明玻璃瓶**：只有一點點保水凝膠，貼好了名牌，裡面有一本小月曆。
4. **一根細繩子**：什麼都沒有，直接把植物吊起來。

「選哪一個，要看你的植物需要什麼。」

> 這就是 **base image**：runtime stage 的 `FROM`。大陶盆是 `debian-slim`，小塑膠盆是 `alpine`，玻璃瓶是 `distroless`，細繩子是 `scratch`。

---

## 大陶盆：什麼都有，就是重

大陶盆最安心。植物要什麼土都有；葉子黃了，盆邊就掛著鏟子和肥料，隨時可以處理。

但它好重，兩個人才搬得動。而且鏟子、肥料放在教室裡，好奇的同學可能會亂挖。

> 這就是 **`debian:trixie-slim`**：有 glibc、bash、apt，debug 最方便；但 image 比較大，多出來的工具也可能被壞人利用。

---

## 小塑膠盆：輕，但土不一樣

小塑膠盆輕多了，一個人就搬得動，還附一支迷你鏟子，有狀況可以稍微處理。

不過阿伯提醒：「這盆用的是**另一種配方的土**。大部分植物種進去都沒問題，但有些植物從小在陶盆的土裡長大，根已經習慣那種土了，換過來會長不好。」

> 這就是 **`alpine`**：很小，有 busybox shell；但它的 C 函式庫是 **musl**，不是 Debian 的 **glibc**。依賴 glibc 的程式放進來會出問題。

---

## 會自己帶養分的植物

小安的樹苗其實很特別。

它是溫室裡用新方法培育的：**所有需要的養分都存在自己的根裡**，不需要土就能活。

可是隔壁小明的向日葵不一樣，它從小就在陶盆的土裡長大，**一離開那種土就枯掉**。小明把向日葵種進玻璃瓶裡，第二天就垂頭了。他很困惑：「植物明明就在瓶子裡啊！」

阿伯說：「植物是在，可是它找不到**它要的那種土**。」

> 這就是 **`CGO_ENABLED=0`**：讓 Go 編出「自己帶養分」的靜態執行檔，不需要 libc。沒關掉 cgo 時，執行檔會去找 glibc 的動態載入器，在 alpine 或 scratch 裡找不到，就出現 `exec /shorty: no such file or directory` —— 檔案明明在，找不到的是它要的那種「土」。

---

## 玻璃瓶：剛好夠，還有名牌和月曆

小安的樹苗不需要土，於是阿伯推薦玻璃瓶。

瓶子很輕，裡面沒有鏟子、沒有肥料，同學想亂挖也沒東西可以挖。但阿伯貼心地在瓶子上放好了兩樣東西：

- **一張通行名冊**：新教室的門口有警衛，名冊上有警衛認得的印章清單，送貨的人來了，對一下印章就知道是不是真的。
- **一本小月曆**：植物要知道現在是什麼季節、什麼時間。

缺點是：植物生病時，瓶子上沒有鏟子可以用。阿伯說：「真的要檢查的話，我這裡有一個**一模一樣、只是附了放大鏡的瓶子**，暫時換過去看就好。」

> 這就是 **`distroless/static`**：沒有 shell、沒有套件管理器，但內建 **CA 憑證**（通行名冊）、**tzdata**（月曆）和 `/etc/passwd`。要 debug 時換成 **`:debug` tag**（附放大鏡的瓶子）。

---

## 細繩子：最輕，但什麼都要自己帶

小安的好朋友小晴更大膽：「我的植物也不需要土，那我用**細繩子**吊起來，連瓶子都不要！」

真的超輕。可是第一天，警衛就把送貨的人擋在門外 —— 因為繩子上**沒有通行名冊**，誰都對不了印章。第二天，植物搞不清楚季節，因為**也沒有月曆**。

小晴只好回溫室，自己影印了一份名冊、一本月曆，綁在繩子上。

> 這就是 **`scratch`**：完全空的 image。要 HTTPS 就要自己 `COPY` CA 憑證，要時區就要自己 `COPY` `/usr/share/zoneinfo`。不然會遇到 `x509: certificate signed by unknown authority` 和 `unknown time zone`。

---

## 順便把葉子修乾淨

搬家前，阿伯還教小安一招：把樹苗身上**做實驗時貼的小標籤**、寫著「溫室第幾排第幾格」的牌子都拿掉。植物本身一點都沒變，但輕了一點，而且不管在哪個溫室種，看起來都一模一樣。

> 這就是 **`-ldflags "-s -w"`**（拿掉除錯用的符號）和 **`-trimpath`**（拿掉 build 機器上的路徑）：執行檔從 ~18MB 變 ~12.5MB。

---

## 另外兩位同學的植物

**鐵匠阿姐家的仙人掌**有兩種種法：一種從小種在陶盆土裡，搬家要配**跟原本同一批的土**（玻璃瓶加一點點土的那種）；另一種是用新方法培育、自帶養分，就能直接用細繩子吊。

> 這就是 **Rust**：預設動態連結 glibc，用 `distroless/cc`；用 musl 靜態連結（`rust:alpine`）就能放進 `scratch`。

**音樂盒阿伯的鈴蘭**一定要有一台**小噴霧機**一直噴水才能活。所以不管選哪種盆子，盆子裡都得放一台噴霧機 —— 選擇的重點不在輕重，而是噴霧機跟盆子合不合。

> 這就是 **Node**：一定要有 Node.js runtime，所以選 `node:24-slim`（最相容）、`node:24-alpine`（小一點，但 musl 的土要注意 native addon）、或 `distroless/nodejs`（最少東西）。

---

## 小安的選擇

最後小安選了**玻璃瓶**：樹苗自帶養分，玻璃瓶剛好有名冊和月曆，又輕又安全；要檢查時，還有附放大鏡的版本可以換。

> 這就是 **shorty 的選擇**：`CGO_ENABLED=0` 的靜態執行檔 + `gcr.io/distroless/static-debian12`，image 約 15MB。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 選盆子 | 選 runtime 的 **base image** |
| 大陶盆（土、鏟子、肥料） | **`debian:trixie-slim`**（glibc、bash、apt） |
| 小塑膠盆（另一種配方的土） | **`alpine`**（musl、busybox） |
| 透明玻璃瓶 | **`distroless/static`** |
| 細繩子 | **`scratch`** |
| 兩種不同配方的土 | **glibc** vs **musl** |
| 自帶養分、不需要土的樹苗 | **`CGO_ENABLED=0`** 的靜態執行檔 |
| 向日葵找不到它要的土 | `exec ...: no such file or directory` |
| 警衛的通行名冊 | **CA 憑證** |
| 被擋在門外 | `x509: certificate signed by unknown authority` |
| 小月曆 | **tzdata** |
| 附放大鏡的瓶子 | distroless 的 **`:debug` tag** |
| 拿掉實驗標籤和溫室位置牌 | **`-ldflags "-s -w"`**、**`-trimpath`** |
| 仙人掌的兩種種法 | Rust：glibc + `distroless/cc`，或 musl + `scratch` |
| 一定要放噴霧機的鈴蘭 | Node 一定要有 runtime |

## 一句話記住

> **盆子要看植物需要什麼：自帶養分的樹苗（靜態執行檔）放進有名冊和月曆的玻璃瓶（distroless）最剛好；需要特定土的植物，盆子的土一定要對（glibc／musl）。**
