# 故事版：阿哲第一次在夜市擺攤 🏮

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「阿哲第一次去夜市擺攤賣東西」的故事，幫你「感覺」出安裝 Docker、Windows 為什麼需要 WSL2、`docker run hello-world`、背景執行 `-d`、port 對應 `-p 8080:80`、以及第一次 pull image 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 先要有一塊能擺攤的地

阿哲想在夜市賣他最拿手的檸檬愛玉。

可是夜市有規定：**所有攤位都要擺在「夜市專用地板」上**，那種地板有統一的電線插座、統一的排水溝，攤車推上去就能用。

阿哲住的社區沒有夜市地板，只有一般的停車場。

管理委員會說：「沒關係，我們有一種**可以摺起來的夜市地板**，鋪在停車場上，上面就跟真正的夜市一模一樣。」

> 這就是 **Windows／macOS 上的 Docker Desktop + WSL2**：container 需要 Linux kernel（夜市專用地板），Windows 沒有，所以 Docker Desktop 用 WSL2 鋪了一台輕量 Linux VM。在 Linux 上就不需要，因為地本身就是夜市地板（直接裝 Docker Engine）。

---

## 申請攤位、領到工作證

阿哲去管理處辦手續：

1. 先確認停車場夠平、夠大（**有開虛擬化**）。
2. 鋪好摺疊夜市地板（**`wsl --install`**）。
3. 領一張工作證和一支對講機，以後要做什麼事，用對講機跟管理處說就好（**安裝 Docker Desktop**）。

他拿起對講機試試看：「喂喂，聽得到嗎？」

對講機傳來兩個聲音：「這裡是阿哲的對講機，型號 A。」「這裡是夜市管理處，我們在夜市地板上，一切正常！」

> 這就是 **`docker version`**：會看到兩段，**Client**（你手上的對講機，Windows 程式）和 **Server**（管理處，跑在 Linux 上）。只有 Client 沒有 Server，就是管理處沒開門——打開 Docker Desktop 等它變 Engine running。

---

## 第一個測試：「哈囉，有人在嗎？」

管理處說：「第一次來的人，我們都會請你先擺一個**超迷你的試營業攤**。」

阿哲用對講機說：「我要擺一攤『哈囉』。」

管理處回答：「你的倉庫裡沒有『哈囉』攤車耶，我先去**總倉庫**幫你領一台。」

過了幾秒，一台小小的攤車推上夜市地板，攤車上的小喇叭大聲唸出：「**哈囉！你的攤位申請成功了！這台攤車是管理處從總倉庫領來、推到地板上、打開喇叭唸給你聽的！**」

唸完，攤車就收起來了。

阿哲再說一次：「我還要一攤『哈囉』。」這次管理處沒有跑總倉庫，**直接從阿哲的倉庫**推出一台新的。

> 這就是 **`docker run hello-world`**：本機沒有 image 就先從 Docker Hub（總倉庫）pull，再建一個 container 跑起來。程式印完訊息就結束，container 也跟著結束。第二次跑不用再下載，因為 image 已經在本機了。

---

## 真正的攤位：一直開著的愛玉攤

試營業成功，阿哲要開他真正的愛玉攤了。

愛玉攤跟「哈囉」攤不一樣：它不是唸一句話就收，而是**要一直開著**，等客人一個一個來買。

阿哲說：「我要擺一攤愛玉，**開好之後不用叫我**，我要去旁邊跟朋友聊天。」

管理處說好，把攤車推上地板，給了阿哲一張號碼牌：「3f2a1b…，這是你攤位的編號。」然後阿哲就可以離開，攤位自己繼續營業。

> 這就是 **`docker run -d nginx`**：`-d`（detached）讓 container 在背景執行，印出 container ID（號碼牌）就把終端機還給你。nginx 是常駐的網頁伺服器，會一直跑到你叫它停。不加 `-d`，你就得一直站在攤位前顧著。

---

## 客人從哪一個窗口買？

攤位擺好了，可是過了半小時，一個客人都沒有。

原來，阿哲的攤位擺在**夜市地板的中間**，四周都圍著布簾，外面的人根本看不到，也走不進來。攤位裡的阿哲對著「80 號小窗口」喊：「愛玉！好吃的愛玉！」但那個窗口是對著布簾裡面的。

管理處提醒他：「你要跟我們登記，**把布簾外的 8080 號大窗口，接到你攤位裡的 80 號小窗口**。」

登記好之後，客人走到停車場邊的 8080 號大窗口喊一聲，聲音就會被傳到阿哲攤位裡的 80 號小窗口。愛玉一碗一碗賣出去了！

隔壁的小美也賣愛玉，她攤位裡也是 80 號小窗口。沒關係，她登記的是外面的 **8081** 號大窗口。兩攤裡面的小窗口號碼一樣，外面的大窗口不一樣，就不會搶客人。

> 這就是 **`-p 8080:80`**：左邊是主機的 port（外面的大窗口），右邊是 container 裡的 port（攤位裡的小窗口）。不加 `-p`，主機的 `localhost` 根本連不到 container。兩個 nginx 都 listen 80 不會衝突，只要主機那邊的 port 不同（`-p 8081:80`）。第 12 章會講窗口背後怎麼轉的。

---

## 大窗口已經有人用了！

隔天，阿哲又想多開一攤，也想用 8080 號大窗口。

管理處說：「**不行喔，8080 號窗口已經有人在用了。**」

阿哲才想起來，昨天那攤還開著。他只好改登記 8082 號窗口。

> 這就是 **`port is already allocated`**：主機的 port 同時只能給一個人用。換一個 port（`-p 8082:80`），或先把佔用的 container 停掉。Windows 上有些窗口號碼還會被系統先保留起來，用 `netsh interface ipv4 show excludedportrange protocol=tcp` 查得到。

---

## 收攤

夜市結束了，阿哲用對講機說：「愛玉攤，**收攤**。」攤位停止營業，燈關了，但攤車還停在地板上。

再說一聲：「**把攤車推走**。」地板上就空出位置了。

> 這就是 **`docker stop web`** 和 **`docker rm web`**：stop 讓 container 停下來（還在），rm 才真的把它刪掉。兩者差別和整個生命週期，第 04 章會細講。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 夜市專用地板 | **Linux kernel** |
| 鋪在停車場上的摺疊夜市地板 | **WSL2 的 Linux VM**（Docker Desktop） |
| 本來就是夜市地板的地 | **原生 Linux** + Docker Engine |
| 確認停車場夠平夠大 | BIOS 開啟**虛擬化** |
| 手上的對講機 | **`docker` CLI**（Client） |
| 夜市管理處 | **Docker daemon**（Server） |
| 「喂喂，聽得到嗎？」 | **`docker version`** |
| 總倉庫 | **Docker Hub**（registry） |
| 「哈囉」試營業攤 | **`docker run hello-world`** |
| 唸完就收起來的攤 | 主 process 結束 → container 結束 |
| 一直開著的愛玉攤 | 常駐服務 **nginx** |
| 「開好之後不用叫我」 | **`-d`**（背景執行） |
| 號碼牌 3f2a1b… | **container ID** |
| 外面的大窗口 → 攤位裡的小窗口 | **`-p 8080:80`**（主機 port → container port） |
| 8080 號窗口已經有人在用 | **`port is already allocated`** |
| 收攤 / 推走攤車 | **`docker stop`** / **`docker rm`** |

## 一句話記住

> **先鋪好夜市地板（Docker Desktop + WSL2），用對講機（CLI）叫管理處（daemon）推攤車出來；要一直營業就加 `-d`，要客人買得到就登記外面的大窗口接到攤位裡的小窗口（`-p 8080:80`）。**
