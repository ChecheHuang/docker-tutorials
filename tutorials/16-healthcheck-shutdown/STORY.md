# 故事版：摩天輪的打烊廣播 🎡

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「夜間遊樂園摩天輪」的故事，幫你「感覺」出 HEALTHCHECK、liveness 與 readiness、distroless 沒有 curl 的問題、PID 1 與訊號、exec form 與 shell form、docker stop 的 10 秒、`--init` 和優雅關機是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 巡邏員的對講機

星光遊樂園晚上也開放，最受歡迎的是一座大摩天輪。負責開摩天輪的是阿明叔叔，他一個人坐在小小的控制亭裡。

遊樂園有一位巡邏員小芬姐姐，她不可能整晚盯著每一座設施。所以她有一個習慣：**每隔十分鐘，用對講機呼叫一次**：「摩天輪，摩天輪，還好嗎？」

阿明叔叔只要按一下對講機回「好」，小芬就在本子上畫一個綠色勾勾。如果呼叫了**連續三次都沒回應**，她就把摩天輪那一格塗成紅色。

剛開園的前十分鐘，阿明叔叔還在開燈、暖機，沒空回話也沒關係，小芬不會算他失敗。

> 這就是 **HEALTHCHECK**：Docker 每隔 `--interval` 在 container 裡跑一次檢查，連續失敗 `--retries` 次就標成 `unhealthy`。剛開園那十分鐘就是 `--start-period`，暖機期間的失敗不算數。

### 塗成紅色，然後呢？

有一次摩天輪那格被塗紅了，小芬只是在本子上記下來，**並沒有跑過去把阿明叔叔換掉**。換人這件事，要等總部的大隊長來決定。

> 這就是 **unhealthy 的意義**：單機 Docker 看到 unhealthy **不會自動重啟**，只會把狀態標出來。真正會「換人」的是 Swarm、Kubernetes 這種總部。

---

## 「你醒著嗎？」和「能載客嗎？」

有一天晚上停電了一小段時間，摩天輪的馬達不能轉。阿明叔叔還是好好地坐在控制亭裡。

小芬呼叫：「還好嗎？」

阿明叔叔有點猶豫——**他人是好好的**，可是**現在沒辦法載客**。

小芬想了想，把問題分成兩種：

- 「阿明，**你醒著嗎**？」——醒著就回「好」。如果連這都不回，那真的要換人了。
- 「摩天輪**現在能載客嗎**？」——停電就回「還不行」。這時候不用換人，換了也沒用，電又不是阿明弄壞的。只要請售票口**先別賣票**就好。

如果只問第二種，一停電，所有設施的操作員都會被當成「壞掉了」全部換掉——電來了以後，一群新人還得重新熟悉機器，反而更慢。

> 這就是 **liveness 和 readiness**：`/healthz` 只問「你活著嗎」，失敗才該重啟；`/readyz` 問「你的依賴（DB、Redis）都好了嗎」，失敗只是先別導流量進來。把 readiness 當 liveness 用，DB 一抖所有副本會一起被重啟。

## 控制亭裡沒有對講機

遊樂園後來蓋了一座新的摩天輪，控制亭設計得**超級簡單**：只有一張椅子和開關，沒有電話、沒有對講機、沒有任何多餘的東西。這樣小偷也沒東西可偷，壞掉的機會也少。

可是問題來了：小芬要怎麼問「還好嗎」？

有人說：「那就在亭子裡裝一整套電話系統啊！」可是那會把亭子塞滿，又多了好多會壞的東西。

最後工程師做了一個**只有一顆按鈕的小鈴鐺**，掛在亭子裡。小芬一拉繩子，阿明叔叔按一下鈴鐺回應，就這樣，只做這一件事。鈴鐺是另一個工作室做好送過來的，不是在摩天輪工地上做的。

> 這就是 **distroless 沒有 curl 的問題**：shorty 的 image 沒有 shell、沒有 curl，`HEALTHCHECK CMD curl ...` 根本跑不起來。解法是自己編一個只會打 HTTP 的迷你 **probe** 程式放進去。鈴鐺從別的工作室送來，就是用 `--build-context probe=...` 把 build context 以外的資料夾送進 build，再 `COPY --from=probe`。

## 打烊廣播

晚上十點，遊樂園要打烊了。廣播響起：

「各位遊客，本園將於**十分鐘後**關閉電源，請各設施準備收場。」

阿明叔叔聽到廣播，馬上做三件事：

1. **不再讓新的客人上車廂。**
2. 讓還在上面的車廂慢慢轉下來，一個一個把客人送下來。
3. 全部客人都下來了，關掉開關，對著對講機說：「摩天輪收好了，掰掰！」

他給自己訂了規矩：**八分鐘內一定要收完**，因為十分鐘一到，總電源會直接被切掉，管你車廂上有沒有人。

> 這就是 **graceful shutdown**：`docker stop` 送 SIGTERM，shorty 停止接新請求、把進行中的請求做完（`srv.Shutdown`），印出 `bye` 才結束。shorty 給自己 8 秒，比 Docker 的 10 秒短，免得被 **SIGKILL**（直接切電）打斷。

### 想多等一下？

如果某天客人特別多，園長可以改廣播：「本園將於**二十分鐘後**關閉電源。」

> 這就是 `docker stop -t 20`、`docker run --stop-timeout`，以及 Compose 的 `stop_grace_period: 20s`。

## 坐在門口的那個人

有一陣子，阿明叔叔的表弟小強也來幫忙。小強坐在控制亭的**最前面靠門口**的位置，阿明叔叔坐在後面操作。

打烊廣播只會傳到**坐在門口的那個人**耳朵裡。

問題是：小強聽到廣播，**什麼也沒說**。他沒有轉頭告訴阿明，自己也不知道要做什麼。而且遊樂園有個規矩：坐門口的人如果沒有「我知道要怎麼處理廣播」的工作證，廣播對他來說**就像沒聽到一樣**。

結果阿明叔叔一直不知道要打烊，摩天輪照轉。十分鐘一到，**啪**，總電源切掉，車廂停在半空中，客人卡在上面好久才被救下來。

隔天園長下令：「控制亭**門口那個位子，只能坐真正會操作摩天輪的人**。」阿明叔叔自己坐到門口，廣播一響他馬上聽到，事情就順了。

> 這就是 **PID 1 與 shell form 的問題**：`docker stop` 的 SIGTERM 只送給 PID 1。shell form（`CMD /shorty`）讓 `/bin/sh` 坐在 PID 1，它不轉交訊號；PID 1 沒裝 handler 的訊號會被忽略，10 秒後就是 SIGKILL，exit code 137。**exec form**（`ENTRYPOINT ["/shorty"]`）讓 shorty 自己當 PID 1，這就是園長的新規矩。

## 專業傳令員

隔壁的旋轉咖啡杯也有類似的問題：操作員是新手，**根本不知道聽到廣播該怎麼辦**。

遊樂園派了一個專業傳令員坐在咖啡杯的門口。他很瘦小、不佔位子，只會兩件事：

- 聽到廣播，就**轉告坐在他正後方的那個人**。
- 有人下班走了，幫忙**把他留下的空杯子收乾淨**，不讓亭子越堆越亂。

不過傳令員只會轉告**正後方那一個人**。如果正後方坐的又是像小強那樣不傳話的人，後面的人還是聽不到。

> 這就是 **`--init`（tini）**：在你的程式前面插一個極小的 init 當 PID 1，幫忙轉送訊號、收殭屍行程。但它只轉給直接子行程，所以救不了 shell form；治本還是 exec form。shorty 會自己處理廣播，也不會留下空杯子，所以不需要它。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 每十分鐘用對講機問「還好嗎」 | **HEALTHCHECK** `--interval` |
| 連續三次沒回應就塗紅 | `--retries` → `unhealthy` |
| 開園暖機的十分鐘不算 | `--start-period` |
| 塗紅了但沒人來換人 | 單機 Docker **不會因 unhealthy 重啟** |
| 「你醒著嗎？」 | **liveness**：`/healthz` |
| 「能載客嗎？」停電時先別賣票 | **readiness**：`/readyz`，依賴沒好就先別導流量 |
| 超簡單、什麼都沒有的控制亭 | **distroless** image（沒有 shell、沒有 curl） |
| 只有一顆按鈕的小鈴鐺 | 自己編的迷你 **probe** 執行檔 |
| 鈴鐺從別的工作室送來 | `--build-context probe=...` + `COPY --from=probe` |
| 打烊廣播 | **SIGTERM**（`docker stop`） |
| 十分鐘後總電源切掉 | 10 秒後 **SIGKILL**，exit 137 |
| 不讓新客人上、把車廂轉下來、說掰掰 | **graceful shutdown**：`srv.Shutdown` → `bye` |
| 八分鐘內收完 | shorty 的 8 秒 shutdown timeout |
| 改成二十分鐘後斷電 | `docker stop -t`、`stop_grace_period` |
| 只有門口的人聽得到廣播 | 訊號只送給 **PID 1** |
| 坐門口卻不傳話的小強 | **shell form**：`/bin/sh` 當 PID 1 |
| 門口只能坐會操作的人 | **exec form**：`ENTRYPOINT ["/shorty"]` |
| 專業傳令員 | **`--init`**／tini |
| 幫忙收空杯子 | 回收**殭屍行程** |

## 一句話記住

> **巡邏員定期問「還好嗎」，但「醒著」和「能載客」要分開問；打烊廣播只會傳到門口那個人，所以門口一定要坐真正會收場的人（exec form），而且要在斷電前收完。**
