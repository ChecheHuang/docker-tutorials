# 故事版：夏令營的緊急演習日 🏕️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「夏令營輔導員一天之內練習處理六種狀況」的故事，幫你「感覺」出 OOM 循環重啟（exit 137）、磁碟被 image／log 塞滿與 log rotation、時區錯誤與 tzdata、container 內 DNS 失敗、port 衝突、殭屍行程與 `--init` 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 演習日的規矩

森林夏令營每年都有一天是「**緊急演習日**」。營長阿德把新來的輔導員小雨叫過來：

「今天我會**故意**製造六種狀況。每一種你都要說出四件事：**看到什麼、怎麼查、怎麼救、以後怎麼防**。真的出事那天，你不會有時間翻手冊。」

小雨拿出筆記本，畫了一張表格：症狀、重現、排查、修正、預防。

> 這就是本章每個演練的格式：**症狀／重現步驟／排查流程／修正／預防**。排查的第一步永遠是那三招：`docker ps -a`、`docker logs`、`docker inspect`。

---

## 狀況一：背包太重，一直被請下車

第一個狀況：營隊規定每個小朋友的背包**最多 5 公斤**。小胖的背包裝了一堆零食，一上遊覽車，司機量一量——超重——**二話不說請他下車**。

小胖下車後，媽媽把他送回車上……背包還是那麼重，又被請下車。上車、下車、上車、下車，一整個早上。

最奇怪的是，小胖自己的日記裡什麼都沒寫：他根本不知道自己為什麼一直被趕下來。

小雨去問司機，司機翻了翻紀錄本：「**超重請下車**，第三次了。」

> 這就是 **OOM 循環重啟**：container 超過記憶體上限，kernel 直接 SIGKILL（exit 137 = 128 + 9），app 的 log 不會留下任何訊息。`restart` policy 又把它重開，於是一直循環。看司機的紀錄本：`docker inspect --format '{{.State.OOMKilled}}'`、`docker events --filter event=oom`。修正是調高上限或減少用量；Go 用 `GOMEMLIMIT` 讓自己在接近上限前先整理背包。

---

## 狀況二：倉庫塞爆了

第二個狀況：營隊的倉庫門打不開了。

小雨用力推開一看：裡面堆滿了**歷年的舊帳篷**、做活動剩下的**半成品**、還有一本**越寫越厚的值班日記**——每個值班的人每分鐘都寫一句「一切正常」，三年下來已經疊到天花板。

小雨先拿出倉庫清單算一算：舊帳篷佔多少、半成品佔多少。可是那本日記不在清單上，要另外去量。

清理時她很小心：舊帳篷、半成品可以丟，但**小朋友的作品箱**絕對不能丟，那是要寄回家的。

最後營長規定：值班日記**每本最多 10 頁，最多留 3 本**，寫滿了就把最舊的那本收掉。

> 這就是 **磁碟被塞滿**：`docker system df` 是倉庫清單（image、container、volume、build cache），但 **log 不在清單上**，要用 `docker inspect --format '{{.LogPath}}'` 另外查。清理用 `docker builder prune`、`docker image prune`；`docker volume prune` 會刪掉作品箱（資料），要先確認。預防是 log rotation：`max-size: "10m"`、`max-file: "3"`，寫在 `daemon.json` 或 compose 的 `logging:`。

---

## 狀況三：時鐘慢了八小時

第三個狀況：營隊新買了一個時鐘，掛在餐廳。結果大家早上 7 點到餐廳，時鐘顯示晚上 11 點。

小雨在時鐘背面看到一個旋鈕：「時區：台北」。旋鈕明明轉對了啊！

她打開電池蓋才發現：這個時鐘裡**沒有放「世界時區小冊子」**。它不知道「台北」是什麼意思，又不會抱怨，就**默默用了倫敦時間**。

修法有兩種：去買一本小冊子放進時鐘；或是換一款**內建小冊子**的時鐘，多重一點點，但到哪裡都能用。

營長補充：「其實營隊的正式紀錄本，一律用**世界標準時間**寫。只有貼在布告欄給小朋友看的那張，才換成台北時間。」

> 這就是 **時區錯誤**：`scratch` 和 `alpine` 沒有 tzdata（時區小冊子），設了 `TZ=Asia/Taipei` 也找不到資料，Go 會**不報錯、直接用 UTC**。shorty 用的 `distroless/static` 有 tzdata；用 scratch 時可以 `-tags timetzdata` 或 `import _ "time/tzdata"` 把資料編進執行檔。最好的習慣是：伺服器和資料庫一律存 UTC，顯示時再轉。

---

## 狀況四：在大操場叫名字，沒人回應

第四個狀況：小雨要找廚房的阿芬阿姨拿午餐。她在大操場大喊：「阿芬阿姨——！」

沒有人回應。

原來，營隊裡每一隊都有**自己的帳篷區**，每個帳篷區都有一位**點名員**，你在帳篷區裡喊誰的名字，點名員就會告訴你他在哪一頂帳篷。可是大操場**沒有點名員**，喊破喉嚨也沒用。

阿芬阿姨跟小雨，今天剛好都被叫到大操場集合。

另一種情況是：小雨要打電話給**山下的總部**，可是營隊的電話簿是舊的，總部的號碼換了。她得請營長給她新的電話簿。

> 這就是 **container 內 DNS 失敗**：Docker 的**預設 bridge**（大操場）沒有內建 DNS，只有**自訂 network**（帳篷區）才有點名員 `127.0.0.11`，能用 container 名字互連。compose 預設會建自訂 network，`network_mode: bridge` 就會掉回大操場。連外失敗（公司 DNS、VPN）則是電話簿的問題：`--dns` 或 `daemon.json` 的 `"dns"`。distroless 沒有工具，就用 `docker run --network container:<name> busybox nslookup db` 借一個人進去查。

---

## 狀況五：停車格被佔走了

第五個狀況：載食材的貨車到了，要停在**8 號停車格**，可是那格已經停了一台別人的腳踏車。

小雨先看停車紀錄本：是不是營隊自己的車？不是。再去問附近的管理員：是誰的腳踏車？原來是隔壁營隊的。

解決方法很簡單：請腳踏車移走；或是叫貨車停**18 號格**——反正貨車卸貨的後門位置不變，只是停車格號碼換了。

> 這就是 **port 衝突**：`port is already allocated`（被別的 container 佔）或 `address already in use`（被 host 程式佔）。先 `docker ps --filter publish=8080`，再用 `ss`／`lsof`／`netstat` 找 host 上的程式。修正是停掉佔用者，或換 host port：`-p 18080:8080`，container 裡的 port（後門）不用改。compose 可以寫 `"${APP_PORT:-8080}:8080"`。

---

## 狀況六：沒人收的空便當盒

最後一個狀況：營隊規定，每個小朋友吃完午餐，都要把空便當盒交給**帶隊的大哥哥**，大哥哥點完名才算「這個人吃完了」。

可是有一隊的帶隊大哥哥今天很專心在看地圖，**從來不收便當盒**。小朋友吃完了，拿著空便當盒站在旁邊等，一個、兩個、五個……越站越多。他們已經吃完了，卻還佔著位置，什麼事都不能做。

更麻煩的是：別隊的小朋友如果走散了，也會被送到這位大哥哥這裡——他還是不收。

營長的解法：給這一隊派一位**專門收便當盒的小幫手**站在最前面。小幫手什麼都不做，就只負責收便當盒、點名，還會把營長的廣播轉告給大家。

> 這就是 **殭屍行程**：子行程結束後要由父行程 `wait()` 收屍；孤兒行程會被過繼給 **PID 1**。如果 PID 1 是不懂得收屍的程式（shell script、`sleep`），就會累積一堆 `<defunct>`。修正是 `--init`（compose：`init: true`），讓 tini 當 PID 1 專門收屍、轉發訊號。shorty 是單一 Go process、不 fork，所以不需要。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 症狀／怎麼查／怎麼救／怎麼防 | 症狀／排查流程／修正／預防 |
| 背包上限 5 公斤 | `--memory`／`mem_limit` |
| 超重被請下車 | **OOM killed**，exit 137 |
| 一直被送回車上 | restart policy 造成的循環重啟 |
| 司機的紀錄本 | `.State.OOMKilled`、`docker events --filter event=oom` |
| 倉庫清單 | `docker system df` |
| 舊帳篷、半成品 | 沒用的 image、build cache |
| 小朋友的作品箱 | volume（不能亂 prune） |
| 越寫越厚的值班日記 | json-file log |
| 每本 10 頁、最多 3 本 | `max-size`／`max-file` log rotation |
| 時鐘裡的世界時區小冊子 | **tzdata**（`/usr/share/zoneinfo`） |
| 內建小冊子的時鐘 | `time/tzdata`、`-tags timetzdata` |
| 正式紀錄一律用世界標準時間 | 伺服器、資料庫存 UTC |
| 帳篷區的點名員 | 自訂 network 的內建 DNS `127.0.0.11` |
| 沒有點名員的大操場 | **預設 bridge** |
| 舊電話簿 | 公司 DNS／VPN，`--dns`、`daemon.json` |
| 8 號停車格被佔 | **port 衝突** |
| 改停 18 號格，後門不變 | `-p 18080:8080` |
| 不收便當盒的帶隊大哥哥 | 不會 `wait()` 的 PID 1 |
| 拿著空便當盒等的小朋友 | **殭屍行程** `<defunct>` |
| 專門收便當盒的小幫手 | **`--init`**（tini） |

## 一句話記住

> **事故演練就是先故意弄壞、再照「看到什麼、怎麼查、怎麼救、怎麼防」走一遍：背包超重查 OOMKilled、倉庫塞爆查 system df 和 log、時鐘要有小冊子、叫名字要在有點名員的帳篷區、停車格被佔就換一格、便當盒要有小幫手收。**
