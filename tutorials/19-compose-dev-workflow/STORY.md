# 故事版：漫畫社的描圖紙 ✏️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「漫畫社準備社刊」的故事，幫你「感覺」出 `compose.override.yaml` 自動合併、開發用 image、bind mount 加 air 熱重載、Compose Watch、profiles 和多個 `-f` 檔是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 每改一筆都要送印刷廠

漫畫社的小柏負責畫社刊的封面。封面要交給**印刷廠**，印出來的是又亮又漂亮的正式版。

可是小柏畫畫的時候，每改一根頭髮，都要：

1. 把稿子裝進信封。
2. 送到印刷廠。
3. 等印刷廠印好寄回來。
4. 打開來看：「嗯……頭髮好像還是太長。」

改一筆要等半天。一天下來，他只改了三個地方。

> 這就是**每次都 `docker compose up --build`**：改一行 Go，就要重新 build 上線 image（distroless）、換掉 container。正式版很漂亮，但拿來「一直改一直看」太慢了。

---

## 描圖紙疊在原稿上

社長給小柏一個好方法。

「正式的原稿不要動，**在上面疊一張透明描圖紙**。你在描圖紙上畫草稿、寫註解，從上面看下去，看到的就是『原稿＋你的修改』。」

而且社辦有個規矩：**只要在社辦的桌上打開原稿，描圖紙就會自動疊上去**。因為大家在社辦都是在畫草稿。

如果是拿去**別的地方**、而且特別指定「我只要這幾張」，那就只會拿指定的那幾張，描圖紙不會自己跟過去。

> 這就是 **`compose.override.yaml`**：在同一個目錄、不加 `-f` 執行 `docker compose`，它會自動疊在 `compose.yaml` 上面。一旦用了 `-f` 指定檔案，就只讀你指定的，override 不會自動加入。

### 疊起來的規矩

描圖紙怎麼跟原稿疊在一起，有固定的規矩：

- 原稿上寫「主角穿紅衣服」，描圖紙上寫「主角穿藍衣服」→ 看下去是**藍衣服**（後面的蓋掉前面的）。
- 原稿上有三個角色，描圖紙上**多加一個**角色 → 看下去是四個。
- 原稿上畫了一扇門，描圖紙上**又畫了同一扇門** → 變成兩扇重疊的門，很奇怪。

> 這就是**合併規則**：`image`、`LOG_LEVEL` 這類單一值，後面的覆蓋前面的；`environment` 依名字合併；`ports` 是**疊加**，所以 override 裡不要再寫一次 `8080:8080`。看不清楚疊完長怎樣，就用 `docker compose config`。

## 在白板上直接畫

描圖紙解決了「不要弄髒原稿」，但還沒解決「改一筆要等半天」。

社長又帶小柏到社辦角落的一塊**大白板**前面，白板旁邊站著學姊小芸。

「你直接在白板上畫，」社長說，「小芸學姊會一直盯著白板，**你一畫完一筆，她就馬上用投影機把整張圖投到牆上給大家看**。」

小柏畫了一筆，退後一步——牆上的圖立刻更新了。他又改了眼睛的形狀，三秒鐘後，牆上的主角眼睛就變了。

當然，白板上畫的是**草稿**，用的是白板筆，跟印刷廠的正式版完全不一樣。但這樣改起來超快。

> 這就是 **bind mount + air**：`../../app:/src` 把 host 上的原始碼直接掛進 container（白板就是你自己的檔案），**air** 是小芸學姊，一偵測到 `.go` 檔變了就重新 `go build`、重啟 shorty。這個 container 用的是 **`Dockerfile.dev`**（golang image，有完整工具），不是上線的 distroless——白板筆不是印刷機。

### 學姊有時候沒看到

社辦的白板有點特別：它跟學姊中間**隔著一層霧玻璃**。有時候小柏畫了一筆，學姊根本沒注意到。

後來學姊改成**每半秒鐘轉頭看一次白板**，不管有沒有人叫她。累了一點，但不會漏掉。

> 這就是 air 的 **`poll = true`**：Docker Desktop（特別是 Windows）的 bind mount 常常收不到檔案變更事件，改用輪詢，每 500ms 主動檢查一次。

### 換頁前先打招呼

學姊每次要換投影片之前，會先跟正在台上講解的同學說：「我要換了喔，你講完這句。」等兩秒，才換下一張。

> 這就是 `send_interrupt = true` + `kill_delay`：air 重啟前先送 SIGINT，讓 shorty 走第 16 章的 graceful shutdown，印出 `bye` 才換新版本。

## 印刷廠的小幫手

有時候小柏想確認「**正式印出來**的效果」，白板草稿畢竟不是真的。

印刷廠派了一個小幫手阿德，**坐在小柏旁邊**盯著他的畫稿資料夾。只要資料夾裡的稿子有任何改動，阿德就**自動**把稿子送去印刷廠，印好拿回來換掉舊的那份。

小柏不用自己跑腿，雖然每次還是要等一會兒，但拿到的保證是**跟正式版一模一樣**的成品。

阿德還很聰明：如果小柏只是改了**練習用的速寫本**，他就不送印。

> 這就是 **Compose Watch**（`develop.watch`）：Compose **在 host 上**監看檔案（阿德坐在你旁邊，不隔霧玻璃），`action: rebuild` 有變更就重新 build image、換掉 container，跑的是跟上線一樣的 image。`ignore: ["**/*_test.go"]` 就是「速寫本不送印」。如果 container 裡有自己的熱重載工具，也可以用 `action: sync` 只把檔案複製進去。

## 特殊工具櫃

漫畫社有一個**特殊工具櫃**，裡面放著網點機、大型掃描器。這些東西很佔位子、很耗電，平常不拿出來。

社員來社辦，桌上只會擺出鉛筆、橡皮擦、描圖紙這些**每天都用**的東西。只有說「**今天要用特殊工具**」，工具櫃才會打開，網點機才會擺上桌。

或者直接說「我要用網點機」，它也會被拿出來。

> 這就是 **profiles**：`pgadmin` 加了 `profiles: [tools]`，預設 `docker compose up` 不會啟動它。要用時 `docker compose --profile tools up -d`，或直接 `docker compose up -d pgadmin` 指名它。

## 不同場合疊不同的紙

社刊做完了，漫畫社要拿封面去兩個地方：

- **校內展覽**：在原稿上疊一張「展覽說明」描圖紙。
- **校外比賽**：在原稿上疊一張「比賽規格」描圖紙，規定尺寸、要加作者簽名。

同一張原稿，疊不同的紙，就變成適合不同場合的版本。原稿只有一份，不用畫兩次。

> 這就是**多個 `-f`**：`docker compose -f compose.yaml -f compose.prod.yaml up`，後面的檔案疊在前面的上面。`compose.prod.yaml` 加上 restart 和記憶體限制，`compose.watch.yaml` 加上 `develop.watch`。基礎的 `compose.yaml` 只有一份。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 每改一筆都送印刷廠 | 每次 `up --build` 重 build 上線 image |
| 印刷廠印的正式版 | 上線 image（`app/Dockerfile`、distroless） |
| 原稿 | 基礎 **`compose.yaml`** |
| 透明描圖紙 | **`compose.override.yaml`** |
| 在社辦打開原稿，描圖紙自動疊上 | 同目錄、不加 `-f` 時**自動合併** |
| 指定「只要這幾張」 | 用了 `-f` 就不自動讀 override |
| 紅衣服被蓋成藍衣服 | 單一值**後面覆蓋前面** |
| 同一扇門畫兩次 | `ports` 是**疊加**，不要重複寫 |
| 大白板 | **bind mount**（`../../app:/src`） |
| 盯著白板、馬上投影的學姊 | **air** 熱重載 |
| 白板筆不是印刷機 | **`Dockerfile.dev`**（golang + air） |
| 霧玻璃後每半秒轉頭看一次 | air 的 **`poll = true`** |
| 換投影片前先打招呼 | `send_interrupt` → graceful shutdown |
| 坐在旁邊、自動送印的小幫手 | **Compose Watch** `action: rebuild` |
| 速寫本不送印 | `develop.watch` 的 **`ignore`** |
| 特殊工具櫃 | **profiles**（`profiles: [tools]`） |
| 「今天要用特殊工具」 | `--profile tools` |
| 網點機 | pgAdmin（`dpage/pgadmin4:9`） |
| 展覽版、比賽版描圖紙 | 多個 **`-f`**：`compose.prod.yaml`、`compose.watch.yaml` |

## 一句話記住

> **原稿只有一份（compose.yaml），在社辦會自動疊上描圖紙（override）；草稿畫在白板上讓學姊馬上投影（bind mount + air），要看正式版就請小幫手自動送印（watch）；特殊工具要開口才拿出來（profiles），不同場合疊不同的紙（-f）。**
