# 故事版：動物園的新手保育員 🦒

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「小安第一天當動物園保育員」的故事，幫你「感覺」出 `docker exec`、`docker logs`、`docker inspect`、`docker stats`、`docker top`、`docker cp`，以及為什麼 container 的 log 要寫到 stdout。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 每一間展區都是關起來的

小安第一天到動物園上班，被分配照顧三間展區：**長頸鹿館**、**企鵝館**、**猴子館**。

每一間展區都是一個大玻璃屋，門鎖得緊緊的。遊客只能從外面看，動物在裡面過自己的生活，吃自己的飯、睡自己的覺。

園長說：「你的工作是**確定牠們都好好的**。可是你不能每次都把整間館拆開來看。我教你幾個工具。」

> 這就是 **container 跑起來之後的樣子**：它是一個隔離的環境，從外面看只知道「在跑」。要知道裡面發生什麼事，就要用本章的六個工具：`logs`、`exec`、`inspect`、`stats`、`top`、`cp`。

---

## 每間館都有一支麥克風

園長帶小安走到控制室，牆上有一排喇叭，每個喇叭上貼著館名。

「每間館裡都裝了一支**麥克風**，」園長說，「動物發出的聲音、管理員在裡面說的話，都會傳到這裡，**而且會錄下來**。你想聽哪一館，就打開那一館的喇叭。」

小安打開長頸鹿館的喇叭，聽到：「早上八點，吃了三把樹葉。」「八點十五分，有遊客在拍照。」

她還可以只聽**最後兩句**、只聽**最近五分鐘**的，或者**一直開著喇叭**，有新聲音就馬上聽到。關掉喇叭，長頸鹿也不會因此停下來。

> 這就是 **`docker logs`**：Docker 會自動收集主 process 寫到 **stdout／stderr** 的所有東西（麥克風）。`--tail 2` 看最後兩行、`--since 5m` 看最近五分鐘、`-f` 持續追蹤。`Ctrl+C` 只是關掉喇叭，container 不會停。

---

## 寫在日記本裡的事，控制室聽不到

過了幾天，猴子館的喇叭一直**靜悄悄的**。小安很擔心：「猴子是不是生病了？」

她跑去一看，猴子好得很，還在盪鞦韆。原來猴子館的管理員不喜歡講話，他把所有事情都**寫在一本日記本裡，鎖在館內的抽屜**。

控制室什麼都聽不到。更糟的是，上個月猴子館重新裝修、整間拆掉重蓋時，那本日記本**跟著舊館一起被清掉了**，剛好那陣子猴子拉肚子，大家想查原因都查不到。

園長說：「以後所有管理員都**對著麥克風講**，不要寫在館裡的日記本。錄音的事交給控制室來管。」

> 這就是 **為什麼 log 要寫 stdout**：寫在 container 裡的 log 檔案，`docker logs` 看不到、container 刪掉就跟著消失、還會慢慢塞滿磁碟。程式只管寫 stdout，收集和保存交給平台。官方 nginx 的 `access.log` 其實就是指向 `/dev/stdout` 的連結；shorty 也是把 JSON log 寫到 `os.Stdout`。

## 從小門走進去看看

有一天，企鵝館的喇叭傳來奇怪的嘎嘎聲。光用聽的，小安看不出問題在哪。

園長給她一把鑰匙：「企鵝館側邊有一扇**員工小門**，你可以從那裡走進去看看。」

小安走進去，看到企鵝老大站在最中間（牠是這間館的**第一號**，大家都聽牠的），旁邊幾隻小企鵝在游泳。原來是水管有點漏水。她看完、記下來，再從小門走出來。

她進去、出來，**企鵝館照常營業**，企鵝老大連頭都沒回。

不過，有一間新蓋的**極地館**，為了安全，**根本沒有員工小門**。要了解那裡面的狀況，小安只能靠麥克風和外面的儀表板。

> 這就是 **`docker exec -it web sh`**：在**正在跑**的 container 裡多開一個 process（從小門走進去），你 `exit` 只是自己離開，主 process（PID 1，企鵝老大）不受影響。停止的 container 不能 exec。像 distroless 這種沒有 shell 的 image（極地館），`exec ... sh` 會失敗，只能用 `logs`、`inspect`、`top` 從外面看。

---

## 每間館的身分資料卡

園長又拿出一疊**資料卡**，每間館一張，上面密密麻麻寫著：

- 館名、什麼時候開館、現在有沒有開
- 館的門牌號碼（園區裡的地址）
- 對外的參觀窗口是哪一個
- 館裡貼的所有**告示**

小安看得頭昏眼花。園長說：「你不用每次都看完整張，**只問你想知道的那一格**就好。例如『企鵝館現在開著嗎？』『長頸鹿館的門牌號碼是多少？』」

小安翻到企鵝館的告示那一格，嚇了一跳：「**飼料倉庫密碼：secret**」——竟然就這樣寫在任何人都能看的卡片上！

> 這就是 **`docker inspect`**：一大包 JSON，記錄 container 的所有設定與狀態。用 `--format '{{.State.Status}}'` 只取某一欄，`{{json .Config.Env}}` 看環境變數。`-e` 傳進去的密碼也會明明白白出現在這裡，第 14 章會講怎麼保護 secrets。`docker port web` 是查「參觀窗口」的捷徑。

---

## 健康手環和點名簿

每隻動物身上都戴著一個**健康手環**，控制室的大螢幕上會即時顯示：長頸鹿館吃了多少飼料、用了多少水、有幾隻動物在活動。

小安發現企鵝館的用水量突然變高，馬上就知道「水管漏水」的問題還沒修好。

另外，每間館門口有一本**點名簿**，可以從外面直接看到「館裡現在有誰在活動」——不用走進去，也不需要館裡有人幫忙點名。有趣的是，企鵝老大在館裡是「**一號**」，在整個動物園的總名冊上卻是「**兩萬三千一百零一號**」。

> 這就是 **`docker stats`** 和 **`docker top`**：stats 即時顯示每個 container 的 CPU、記憶體、網路、磁碟用量（`--no-stream` 只看一次）；top 從外面列出 container 裡的 process，不需要 container 裡有 `ps`。在 container 裡是 PID 1 的 process，從主機看會是另一個號碼（PID namespace）。

---

## 傳遞窗口

最後，園長帶小安看每間館牆上的一個**小小傳遞窗口**。

透過這個窗口，可以把東西**遞進去**（例如一張新的告示），也可以把東西**拿出來**（例如一根掉落的羽毛，拿去給獸醫檢查）。就算館已經關了，也還能從窗口把東西拿出來。

小安遞了一張新告示進企鵝館：「歡迎光臨！」遊客都看到了。

可是隔個月企鵝館**重新裝修、拆掉重蓋**，新館裡當然沒有那張告示。園長說：「想讓每次蓋好的館都有這張告示，要寫進**建館設計圖**，不是從窗口塞。」

> 這就是 **`docker cp`**：在主機和 container 之間複製檔案，`docker cp web:/etc/nginx/conf.d/default.conf ./`（拿出來）、`docker cp index.html web:/usr/share/nginx/html/`（遞進去），停止的 container 也能用。遞進去的東西只存在那個 container 的可寫層；要每次都有，寫進 Dockerfile 的 `COPY`（第 06 章）。

## 回到現實：故事 ↔ Docker 對照表

| 故事裡的東西 | 真正的 Docker 概念 |
|------|------|
| 關起來的玻璃展區 | **container** |
| 每間館的麥克風 | 主 process 的 **stdout／stderr** |
| 控制室的喇叭 + 錄音 | **`docker logs`**（`--tail`、`--since`、`-f`） |
| 關掉喇叭，動物不會停 | `logs -f` 按 `Ctrl+C` 只停止追蹤 |
| 鎖在抽屜裡的日記本 | 寫在 container 裡的 **log 檔案**（反模式） |
| 拆館時日記本被清掉 | container 刪除，可寫層裡的 log 消失 |
| 員工小門 | **`docker exec -it ... sh`** |
| 企鵝老大（第一號） | **PID 1**（主 process） |
| 進去又出來，館照常營業 | exec 的 process 結束不影響 container |
| 沒有員工小門的極地館 | **distroless**（沒有 shell） |
| 每間館的資料卡 | **`docker inspect`** |
| 只問想知道的那一格 | **`--format '{{.State.Status}}'`** |
| 寫在卡片上的倉庫密碼 | `.Config.Env` 裡看得到 `-e` 傳的密碼 |
| 對外的參觀窗口 | **`docker port`** |
| 健康手環 + 大螢幕 | **`docker stats`** |
| 門口的點名簿 | **`docker top`** |
| 館裡一號、總名冊兩萬多號 | 不同 **PID namespace** 的 PID |
| 牆上的傳遞窗口 | **`docker cp`** |
| 寫進建館設計圖 | Dockerfile 的 **`COPY`** |

---

## 一句話記住

> **想知道裡面怎麼了，先聽麥克風（logs），不夠再從小門進去看（exec），查資料卡（inspect）、看手環（stats）和點名簿（top），用傳遞窗口拿放東西（cp）；而且所有事都要對著麥克風講（寫 stdout），不要鎖在日記本裡。**
